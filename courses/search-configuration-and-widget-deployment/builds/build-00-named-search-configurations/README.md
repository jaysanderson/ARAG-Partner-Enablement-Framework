## What you can do after this Build

- Explain why partners store search parameters as a named `search_configuration` instead of hand-carrying them on every `/find`/`/ask` call.
- Create a search configuration via the API and reference it with the `search_configuration` parameter.
- Recognise that this is exactly what the dashboard's "Create widget" step does behind the scenes — the vocabulary for the rest of this course.
