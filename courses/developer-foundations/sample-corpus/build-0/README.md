# Build 0 — Sample Corpus

This folder will hold the 10 sample documents Build 0 ingests. The actual files are to be added by the framework maintainers — they are not in this commit. Suggested mix: 4 PDFs (1 mid-sized report, 3 short articles), 3 markdown files (concept explainers), 3 plain-text files (short blog posts or meeting notes). Total size target: under 20 MB.

Suggested document themes — outdoor / retail / D2C content tends to lend itself well here (think Aurora Outfitters style) so the downstream Build 6/9/10 references hold up. Topics that work well across those Builds:

- An employee profile or staff bio (so "what did Mara recommend for hiking?" style queries land)
- A return / refund policy document
- An onboarding or new-hire process explainer
- A product-care or warranty article
- A trip-report or field-test write-up
- A handful of short articles or notes that round out the corpus and give downstream queries something to find

Used by: Builds 0, 6, 9, 10.
