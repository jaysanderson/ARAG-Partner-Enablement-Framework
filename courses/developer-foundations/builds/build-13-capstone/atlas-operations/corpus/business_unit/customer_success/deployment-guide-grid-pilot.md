# Atlas Grid Pilot Deployment Guide

Deployment guidance for Atlas Grid pilot customers. Product owner Marcus Ortiz; pilot CSM assigned per-customer.

## Phase 1 — Substation profiling (Weeks 1-3)

- Substation single-line diagram review.
- Distribution-side telemetry inventory.
- SCADA integration assessment (each customer's SCADA stack will differ).
- Pilot scope confirmation: 2 to 4 Grid units typical.

## Phase 2 — Substation preparation (Weeks 4-6)

- Physical install bay preparation (typically customer-side scope).
- Cable runs to control room.
- Cyber-security boundary discussion. Atlas Grid sits on the customer's IT/OT boundary — this is rarely a trivial conversation.

## Phase 3 — Atlas Grid install (Weeks 7-9)

- Two-engineer Atlas team on-site (one electrical, one software).
- Per-unit install: 3 days.
- Initial commissioning and SCADA integration.
- **APAC-resident telemetry option:** available since 2028-06-12 (driven by Talos Steelworks evaluation feedback — see `escalation-talos-grid-evaluation-data-residency.md`).

## Phase 4 — Pilot operations (Weeks 10-22)

- 12-week structured pilot.
- Weekly customer engineering review.
- Distribution-side outcome metrics tracked.

## Phase 5 — Pilot decision

- Pilot retrospective with customer's network engineering leadership.
- Expansion business case scoped if pilot succeeds.

## Reference customers

- Meridian Bank — pilot to production transition complete; Phase 2 in negotiation.
- Norvale Energy — pilot Q3 2028 install (conditional on Pulse pilot — see `escalation-norvale-grid-pilot-prereq.md`).
- Talos Steelworks — evaluation phase.
