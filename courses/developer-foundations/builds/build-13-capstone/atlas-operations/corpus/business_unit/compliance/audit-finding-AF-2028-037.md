# Audit Finding AF-2028-037 · Atlas Grid SOX-Pilot Documentation Completeness

**Auditor:** External SOC 2 auditor (NORAM)
**Audit cycle:** Q3 2028 follow-up review
**Status:** Closed
**Severity:** Minor
**Owner:** Marcus Ortiz (Principal Architect)
**Co-owner:** Dr Sara Vance (CCO)

## Finding

The Atlas Grid pilot at Meridian Bank is documented in the Atlas SOX §404 Position as secondary in-scope. The Q3 2028 follow-up review found the Grid-specific control documentation had not been refreshed since the position was first published, even though Grid feature additions in Q1 and Q2 2028 had measurably changed the surface area.

No SOX-material control gap was found in the actual controls; the deficiency is documentation freshness.

## Affected customers

- Meridian Bank (Atlas Grid pilot deployment).

## Remediation

- Atlas Grid control documentation refreshed to reflect the Q1 and Q2 2028 feature surface.
- A quarterly refresh cadence added to Marcus Ortiz's compliance calendar.
- The SOX §404 position document gains a footnote pointing to the latest Grid-specific control doc.

## Closure criteria

- Grid control doc refreshed: Yes.
- Quarterly cadence live: Yes.
- Atlas SOX position cross-reference updated: Yes.

## Closed

2028-10-30 — Dr Sara Vance accepted closure.
