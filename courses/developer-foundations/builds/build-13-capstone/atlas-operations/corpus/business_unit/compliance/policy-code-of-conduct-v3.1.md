# Atlas Code of Conduct v3.1 (POL-CONDUCT-v3.1)

**Owner:** Dr Sara Vance (Chief Compliance Officer)
**Co-owner:** Maya Schwartz (VP People)
**Version:** 3.1
**Effective:** 2027-09-15

## Purpose

This Code applies to every Atlas employee, contractor, partner, and board member. It defines the standards of behaviour Atlas expects, and the boundaries Atlas will not cross.

## Core commitments

1. **Honest dealing.** With customers, with each other, with regulators.
2. **Customer trust.** Customer data is the customer's. We treat it that way.
3. **Equity.** Pay, promotion, and opportunity decisions are made without bias. Annual pay-equity audit per Atlas Code of Conduct §6.
4. **Safety.** Every Atlas product operates within its rated envelope. Where we discover a regression — see INC-2027-0142, INC-2027-0188, INC-2028-0019, INC-2028-0034 — we own it and fix it.
5. **Sustainability.** Carbon-Negative by 2030 is a binding commitment.
6. **Compliance.** GDPR, HIPAA, EU AI Act, NIST 800-53 r5, SOX §404 — each governs us where we touch a customer who's subject to it. We don't argue that we're "not in scope" when we are.

## Reporting concerns

- Atlas operates an anonymous hotline run by a third party.
- Retaliation against good-faith reporters is grounds for dismissal.

## Acknowledgement

Every new Atlas hire reads and acknowledges this Code in their first 30 days. Acknowledgement tracked in HR systems.
