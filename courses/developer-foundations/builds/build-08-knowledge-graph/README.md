## What you can do after this Build

- Recognise graph-shaped customer asks (relationship questions, not document questions).
- Sketch an entity/relation schema for any vertical in 15 minutes.
- Brief an AI to wire `/graph` queries with the data-augmentation filter.
- Demonstrate a question that single-shot retrieval *cannot* answer but graph traversal can.
