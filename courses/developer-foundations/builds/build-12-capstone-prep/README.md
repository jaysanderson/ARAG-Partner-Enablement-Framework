## Start here

1. **[lesson.md](1-lesson.md)** — capstone variant choice, the master prompt set, the 25-minute demo arc.
2. **[walkthrough.md](2-walkthrough.md)** — write the planning doc, pick the variant, draft the 8 master prompts.
3. **[quiz.md](3-quiz.md)** — 5 multiple-choice. Pass = 4/5.

## What you can do after this Build

- Pick the right capstone variant for the partner's book of business (Atlas Enterprise or Aurora CX).
- Write the 8 master prompts that an AI session will execute to build the capstone.
- Sketch the 25-minute customer demo arc end-to-end.
- Defend the build estimate (8 weeks solo / 4 weeks at 2 FTE) in a Progress review board.
