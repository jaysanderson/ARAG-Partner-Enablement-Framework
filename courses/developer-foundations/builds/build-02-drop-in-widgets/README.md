## What you can do after this Build

- Walk a non-technical customer through every section of the Progress Agentic RAG widget configurator without notes.
- Name the four widget types (search bar, search results, chat, popup) and pick the right combination for a given customer.
- Configure widget display, behaviour, and language entirely through the dashboard, no code.
- Filter results to a specific resource subset (e.g. only products) with a single filter expression in the configurator's filter panel.
- Paste the generated embed code into a local HTML file and hand it to a non-technical sales rep who can demo it from their laptop.
