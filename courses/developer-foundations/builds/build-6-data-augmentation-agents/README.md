## What you can do after this Build

- Name ARAG's three data-augmentation agents and what each enriches.
- Match a customer signal to the right agent in seconds ("vocabulary mismatch" → Generator; "filter precision" → Labeller; "relationship traversal" → Graph).
- Brief an AI to write the agent configuration JSON.
- Recognise that the Smart Filters (Build 7) and Knowledge Graph (Build 8) Builds are *applications* of agents you'll configure here.
